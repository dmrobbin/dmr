The rest of a quest
  • giver: who offers it. gates: the rank it holds them below until it's done ({% for index, name in ranks %}{{ index }} {{ name }}{% if not forloop.last %}, {% endif %}{% endfor %}). A gate quest is offered once the player has that rank's points.
  • about: what the log says it is. offer: chatter lines said before it's offered.
  • requires: {"quests": [keys done], "flags": [...], "rank": n}, before it's offered.
  • stages: in order, each {"text", "objectives": [...]}; every objective in a stage, then the next.
  • endings: each {"key", "title", "about", "to" (who it's turned in to: the giver unless it says), "requires" (objectives of its own), "locks" (quest keys it closes), "removes" (CPUs it sends away for good), "flags", "rewards", "script"}. One ending if there's no choice.
  • rewards: {"coins": n}, {"card": serial, "copies": n}, {"pack": {{ packs|join:"|" }}}, {"gift": key}, {"flag": name, "text": "what it means"}. "hidden": true keeps them a surprise.
  • Places: {% for place in places %}{{ place.key }}{% if not forloop.last %}, {% endif %}{% endfor %}. Gifts: {% for gift in gifts %}{{ gift.key }}{% if not forloop.last %}, {% endif %}{% endfor %}.
